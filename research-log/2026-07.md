## 2026-07-23 横断特異 Laplace 積分 I(T) の検証

### 対象

第一標的 potential

```
F(x,y,z) = (x^2 - 1)^2 / 4 + x^2 (y^2 + z^2) + y^6 + y^2 z^2 + z^6
```

の横断特異 germ `K(y,z) = y^6 + y^2 z^2 + z^6` に付随する Laplace 積分

```
I(T) = ∫∫_{R^2} exp(-(y^6 + y^2 z^2 + z^6)/T) dy dz.
```

### 主結果（解析的に厳密）

**1. 厳密な 1 次元 Bessel 表示。**
象限対称性（×4）と双曲座標 `y^2 = s m, z^2 = s/m`（ヤコビアン `1/(2m)`）により
`K = s^2 + s^3 (m^3 + m^{-3})`。内側積分に標準公式
`∫_0^∞ exp(-a(n + 1/n)) dn/n = 2 K_0(2a)`（`n = m^3`）を適用し `s = sqrt(T) x` と置くと

```
I(T) = (4/3) sqrt(T) ∫_0^∞ exp(-x^2) K_0(2 sqrt(T) x^3) dx.
```

定数 `4/3 = 4 · (1/2) · (1/3)`（象限4・ヤコビアン・`n = m^3`）、変数変換すべて誤り無し。

**2. 小 T 漸近。**
`K_0(w) = -ln(w/2) - γ + O(w^2 ln w)`（`w = 2 sqrt(T) x^3`）と
`∫_0^∞ e^{-x^2} dx = sqrt(π)/2`, `∫_0^∞ e^{-x^2} ln x dx = -(sqrt(π)/4)(γ + 2 ln2)` から

```
I(T) = (sqrt(π)/3) sqrt(T) [ log(1/T) + γ + 6 log 2 ] + O(T^{3/2} log(1/T)).
```

- 先頭係数 `sqrt(π)/3 = 0.590817950301839`
- 補正定数 `γ + 6 log 2 = 4.736098748261204`
- log 多重度 `(log 1/T)^1`（RLCT `λ = 1/2`, `m = 2`）
  — Newton 多面体でも独立確認：単項式 `(6,0),(2,2),(0,6)`、対角線が頂点 `(2,2)` で
  境界に当たり Newton 距離 `= 2 ⟹ λ = 1/2`、0 次元面ヒットゆえ `m = 2`。

剰余は相対的に `O(T)`。これが補正付き比の高速収束の理由。

## 2026-07-23 Split-gate capacity の導出と Langevin 数値検証

### capacity 漸近（解析）

`docs/capacity-derivation.md` を追加。split-gate capacity 公式

```
cap_T(A,B) = e^{-H/T} I_K(T) sqrt(mu T / 2pi)
```

を導出し、古典 1 次元 Kramers 則および多次元 Eyring–Kramers 則を**機械精度
（相対差 ~1e-16）で再現**することを確認。本モデル（H=1/4, mu=1, I_K=I(T)）で

```
cap_T ~ (1/(3 sqrt2)) T (log(1/T) + gamma + 6 log2) e^{-1/(4T)},
E[tau_{-→+}] ~ 3 sqrt2 pi^{3/2} T^{1/2} / log(1/T) e^{1/(4T)}.
```

負の logarithmic prefactor exponent `(log(1/T))^{-1}` が観測署名。

### Langevin 平均脱出時間（数値）

`python/langevin_exit_time.py` を追加。3 次元 overdamped Langevin をベクトル化
Euler–Maruyama（dt=1e-3, N=600）で走らせ、左谷 (-1,0,0) から分離面 {x>=0} への
初到達時間を実測。分離面到達時間は well-to-well の 1/2（古典 1 次元関係）なので
予測は `(1/2) 3 sqrt2 pi^{3/2} sqrt(T)/log(1/T) e^{1/(4T)}`。

| T | E[tau] 実測 | 予測(leading) | ratio | g + loglog |
|---|---|---|---|---|
| 0.080 | 20.48 ± 0.80 | 30.11 | 0.680 | 2.084 |
| 0.070 | 27.65 ± 1.06 | 41.80 | 0.662 | 2.056 |
| 0.060 | 44.43 ± 1.64 | 66.33 | 0.670 | 2.068 |
| 0.055 | 61.09 ± 2.46 | 89.97 | 0.679 | 2.082 |
| 0.050 | 85.55 ± 3.25 | 130.85 | 0.654 | 2.044 |

（`g = log E[tau] - 1/(4T) - (1/2) log T`。予測では `g + loglog(1/T) -> const`。）

**結果の解釈。**
- ratio は T を 0.08→0.05 と下げても **~0.67 で安定**（系統的ドリフト無し）。
  functional form `sqrt(T)/log(1/T) e^{1/(4T)}` が T 依存性を正しく捉えている。
- 定数が 1 でなく ~0.67 なのは、この浅い障壁域（1/(4T)=3.1〜5.0）での o(1) 補正。
  leading 定数へは T→0 で漸近的に近づく。
- **識別テスト**：`log(1/T)^{-1}` 因子を入れた reduced 量 `g + loglog` は
  range 0.039（ほぼ一定）。因子を入れない純 power prefactor 仮説では range 0.210
  と単調ドリフト。**5.3 倍の差**でデータは log 補正形を支持 = Newton-degenerate
  署名の数値的証拠。

### 証拠の区分（更新）

- **厳密/既知理論一致**: split-gate 公式、1D Kramers・多次元 EK の再現。
- **数値的に強く支持**: capacity 定数 `1/(3 sqrt2)` と `gamma+6 log2`（cap/refined→1）；
  exit-time の `(log(1/T))^{-1}` 署名（Langevin, 識別テスト 5.3x）。
- **残る課題**: Newton-adapted lower bound の厳密証明（theory.md §9）；
  より低温・多標本での ratio→leading 定数の外挿確認。

## 2026-07-23 精密化：dt 収束・低温拡張・crossover の定量化

**重要な前提。** 主要定数領域は `log(1/T) >> gamma + 6 log2 ≈ 4.74`、すなわち
`T << 0.01` を要する。そこでは脱出時間が `~e^{25}` 以上で直接シミュレーション
不可能。到達可能な `T ∈ [0.04, 0.08]` は crossover 領域。

### (1) dt 収束（離散化バイアスの排除）— T=0.06, N=800

| dt | E[tau] | ratio |
|---|---|---|
| 1e-3   | 43.57 | 0.657 |
| 5e-4   | 43.47 | 0.655 |
| 2.5e-4 | 42.27 | 0.637 |

ratio の変動は ~3%（微減、正の dt バイアスと整合）。**1 からの外れは離散化
アーティファクトではなく真の crossover 定数**。dt=1e-3 で十分。

### (2) 低温拡張と consolidated 解析（7 温度、脱出時間 20→250）

| T | E[tau] | ratio_lead | ratio_refined | C_eff = g + loglog |
|---|---|---|---|---|
| 0.080 | 20.48 | 0.680 | 1.955 | 2.084 |
| 0.070 | 27.65 | 0.662 | 1.840 | 2.056 |
| 0.060 | 43.57 | 0.657 | 1.762 | 2.049 |
| 0.055 | 61.09 | 0.679 | 1.788 | 2.082 |
| 0.050 | 87.22 | 0.667 | 1.720 | 2.063 |
| 0.045 | 131.09 | 0.627 | 1.585 | 2.003 |
| 0.040 | 250.02 | 0.658 | 1.625 | 2.050 |

`ratio_lead = E[tau] / [(1/2) 3sqrt2 pi^{3/2} sqrt(T)/log(1/T) e^{1/4T}]`、
`ratio_refined` は分母の `log(1/T)` を `log(1/T)+gamma+6log2` に置換。

**結論。**
- **署名の確定**：`C_eff = log E[tau] - 1/(4T) - (1/2)log T + log log(1/T)` は
  7 点で **平均 2.055、標準偏差 0.025** と極めて安定。すなわち
  `log E[tau] = 1/(4T) + (1/2)log T - log log(1/T) + 2.055 + o(1)`。
  `-log log(1/T)` 項（= Newton-degenerate 署名）が定量的に確定。
- **識別テスト（全 7 点）**：`1/log(1/T)` 因子を入れた reduced 量は range 0.081、
  入れない純 power 仮説は range 0.286 → **3.5 倍**、log 補正形を支持。
- **crossover の確認**：測定値は leading 予測（ratio 0.66 < 1、分母 log(1/T) のみ
  では大きすぎ）と refined 予測（ratio 1.75 > 1、分母に +4.74 は効かせ過ぎ）の
  **間**にある。真の分母は `log(1/T)` と `log(1/T)+4.74` の間。leading 理論定数
  `C = log(3sqrt2 pi^{3/2}/2) = 2.469` と測定 `C_eff = 2.055` の差 0.414 は、この
  T 域での `o(1)` crossover 補正で、`T → 0` で消える（が直接シミュレーション不可）。

### 精密化の到達点

- 直接シミュレーションで確認できるのは **shape（指数 1/4T、sqrt(T)、log 補正署名）**
  であり、**leading 定数そのものは crossover のため到達不能**。この限界は理論の
  弱点ではなく、`T << 0.01` を要する漸近の性質。
- 未了（あなたの環境向け長時間ラン）：より低温での C_eff 安定性のさらなる確認、
  および well-mass / 分離面係数の finite-T 補正を含む完全 crossover モデルの fit。

### 実行コマンド（精密化）

```
python python/langevin_exit_time.py --temps 0.06 --dt 5e-4 --n-traj 800   # dt 収束
python python/langevin_exit_time.py --temps 0.05 0.045 0.04 --n-traj 800  # 低温拡張
```

## 2026-07-25 定数 J_k の circulant ネットワーク還元

`docs/branching-gate-Jk.md` を追加。branching gate の `cap_T = J_k T` の定数 `J_k` を
解析的に構造化。

- **scale-invariant 変分**：`J_k = inf ∫ |∇h|^2 e^{ρ^k cos(kφ)} dA`。`J_2 = 1`（Morse, 厳密）。
- **circulant k端子ネットワーク還元**：深い谷 = 端子、k回対称 junction は circulant
  Laplacian `G`。`J_k = 1/R_{01}`, `R_{01} = (1/k) Σ_m 4sin^2(πm/k)/λ_m`。
- **共形線形化**：`W = w^k` で重みが `e^{Re W}` に、operator が `Δh + ∂_U h = 0`、
  `g = e^{U/2}h` で `Δg = g/4`（modified Helmholtz, Green 関数 `K_0(·/2)`）。
- **数値検証**（`python/branching_network_reduction.py`）：
  - k=4 パラメータフリー test `cap_opp/cap_adj = (3+r)/4`（r は spectator 値から）：
    実測比と **7–8 桁一致**（|Δ| ~ 1e-8）。
  - spectator 対称性（k=3..6）：相補ペア和 1、対称軸 1/2、残差 2e-8〜5e-5。
- **残る未解決点**：junction 辺コンダクタンス `b_s(k)` の germ `Re[w^k]` からの
  閉形式（modified Helmholtz シート間応答）。これが求まれば `J_k` は完全に閉じる。

## 2026-07-26 b_s(k)：分数次数ベッセルモード解

`docs/branching-gate-bs.md` ＋ `python/branching_bessel_modes.py` を追加。J_k の最後の
1ピース（junction 辺コンダクタンス b_s）を解析構造化。

- **厳密モード解**：共形写像 `W = w^k` → modified Helmholtz `Δg = g/(4T^2)`
  （`g = e^{U/2T} h`）→ 変数分離で committor は分数次数変形ベッセルのモード和：
  `h = e^{-U/2T} Σ_m α_m I_{|m|/k}(ρ^k/2T) e^{imφ}`。分数次数 `m/k` が k 分岐の署名。
- **数値検証**：FD committor を `e^{imφ}` に射影、比 `ĝ_m/I_{|m|/k}(ρ^k/2T)` が ρ に対し
  一定（k=4, 相対ばらつき <0.7%）。係数 α_0=α_4=1/2, α_1=α_3=0.143, α_2=0.204。
- **connection problem**：channel m は aliased order `|m/k+n|` を励起、ridge boundedness
  が係数を選ぶ。初等閉形式は一般に無し。第一撃と同じ K_0/I_ν ベッセル族。
- **数値 closed-out**：channel admittance `a_m = λ_m/T` を effective resistance から逆算
  （k=3..6）。`J_k = 1/R_01` がネットワーク公式で閉じる。J_2=1（Morse, erfc）は厳密。

到達点：b_s を「未知の 2D PDE 定数」から「分数次数ベッセルの explicit connection problem
＋数値確定した定数」へ前進。残るは admittance の初等的閉形式のみ。

## 2026-07-27 channel admittance の k→∞ 漸近

`docs/branching-gate-largek.md` ＋ `python/branching_admittance_asymptotics.py` を追加。

- **直接測定法**：全 k 谷を Fourier mode `cos(2πmj/k)` に固定し谷0への正味電流＝λ_m を測定。
  Dirichlet form の T 因子ゆえ raw current が scale-invariant `a_m=λ_m/T` に等しい（初回、
  誤って /T して 1/T 倍ずれたのを修正）。circulant 逆算値と一致（a_1(k=4)=1.383 等）。
- **円筒極限**：単位円近傍ズーム `u=k(ρ-1), ψ=kφ` で重みが普遍的 `e^{e^u cosψ}` に収束。
  circulant スペクトル → 無限谷鎖の分散関係 `Λ(q)=Σβ_s(1-cos qs)`, `q=2πm/k`。
- **結果**：`a_m ~ 2πm/k`（m 固定, k→∞）。c_m=a_m k/(2πm) が m=1,2,3 で単調に 1 へ
  （k=3..14、<1% で slope 1 を確認）。λ_m ~ 2πmT/k。J_k は k→∞ で ~0.79 へ飽和。
  結合裾 β_s ~ (2/π)/s²（漸近としてのみ、有限 k の b_s は folding で外れる）。
- **未決**：slope が厳密 1 の解析的証明（円筒問題の Λ'(0+)=1）、J_∞ の閉形式。

## 2026-07-27 分散関係の傾き Λ'(0⁺)=1 の証明

`docs/branching-gate-slope.md` ＋ `python/branching_steklov_slope.py` を追加。
`a_m ~ 2πm/k` を精密化し閉形式と傾きを確定。

- **閉形式**：`a_m = 2 sin(πm/k)`、`Λ(q) = 2 sin(q/2)`、`Λ'(0⁺) = 1`。
- **機構（Steklov/DtN）**：大 k で単位円内部は一様導体（重み→1）、深井戸は境界の完全
  リザーバー接点。単位円板の DtN 固有値は mode e^{imφ} に厳密に |m|（分散が |q| 線形に
  なる理由）。谷 territory `[-π/k,π/k]` で電流密度 `|m|cos(mφ)` を積分 → `2 sin(πm/k)`。
- **結合**：`β_s = 8/(π(4s²-1)) ~ (2/π)/s²`。有限リング結合は committor 抽出値と 3–6 桁一致。
- **数値**：全 q∈(0,π] で `a_m/2sin(πm/k) → 1`（k=6..16, T=0.10; k・T 両方で 1 へ収束）。
  全測定点が `2 sin(q/2)` に collapse（figures/branching_steklov_dispersion.png）。
- **未決**：理想化誤差の厳密 bound、J_∞ の閉形式（Λ から原理的に計算可能）。

## 2026-07-27 隣接容量定数 J_∞ = π/4

`docs/branching-gate-slope.md` に追記、`python/branching_steklov_slope.py` を拡張。

## 2026-07-27 理想化 a_m=2sin(πm/k) の誤差評価

  ~0.1% 一致（全 k）。閉形式は large-k 漸近でなく **有限 k でも scale-invariant 極限で厳密**。
  残差 ~1e-3 は有限井戸半径の数値バイアス。
- **有限 T 補正**：`a_m = 2sin(πm/k)(1 - c_m(k)T + O(T²))`, `c_m(k)~c_m/k²`,
  `c_1≈3.4`, `c_2≈5.8`。envelope `|a_m/2sin-1| ≲ 6T/k²`。相対誤差は T に線形で切片→0
  （figures/branching_gate_error.png）。
- **厳密/数値の区分**：変分（Dirichlet inf）→重みに単調（比較 bound の枠組み）は厳密；
  T→0 厳密性と O(T/k²) 補正は数値確定；`c_m(k)` の proven-constant 閉形式のみ未決。
- **solver 信頼域**：重み動的範囲 `e^{(k/2)/T}`、float64 超えで発散するので `T≳(k/2)/37`。
- 帰結：`Λ=2sin(q/2)`, `Λ'(0⁺)=1`, `J_k=(k/2)tan(π/2k)`, `J_∞=π/4` はすべて T→0 で厳密、
  有限 T では O(T) 補正。degree-k branching gate の large-k 構造が誤差評価込みで閉じた。

## 2026-07-27 Case III：non-splittable gate（PDE-algebraic invariant）

- **モデル**：`F = -x^4 + a x^2 y^2 + y^4 + (x^2+y^2)^3`。±x に 2 井戸、原点に退化ゲート。
  Case I,II の外：Hessian=0（split 不適用）、非調和 `Δ(-x^4+x^2y^2+y^4)=-10x^2+14y^2≠0`
  （共形線形化不適用）、a≠0 で非分離。
- **scaling**：`cap ~ J(a) T`（degree-4 homogeneous, d=2 → p=1；数値 p≈0.93→1）。
- **主結果**：Newton 多面体 `{(4,0),(2,2),(0,4)}` は a 非依存なのに `J(a)` は a とともに
  単調変化（fixed T、外挿なし、両 T で単調）。a=0→3 で約 24% 減少。

  Case I（split）で `(κ,r)=横断 Newton data`（係数非依存）だったのと対照的。
- **分離性**：a=0 の leading germ `-x^4+y^4` は分離的（committor が x のみの 1D 還元）。

## 2026-07-27 Case III 定数 J(a) の閉形式

`docs/nonsplittable-Ja.md` ＋ `python/nonsplittable_Ja.py` を追加。純 germ
`F=-x^4+a x^2 y^2+y^4`（homogeneous degree 4 ⇒ T=1 で cap=J(a)）を confinement 無しで直接計算。

- **J(0)=1（厳密）**：a=0 で重み e^{x^4-y^4} 分離、committor 1D。
  `J(0)=[∫e^{-x^4}]^{-1}·∫e^{-y^4}=1`。数値 domain-indep で 1.011→1.000。
- **J'(0)=-（Γ(3/4)/Γ(1/4)）²=-2π²/Γ(1/4)⁴≈-0.11424（厳密）**：envelope 定理、
  `h_0'=e^{-x^4}/∫e^{-x^4}`。反射公式 Γ(1/4)Γ(3/4)=π√2 を使用。
  数値 tangent slope -0.11419 と 4 桁一致。
- **full J(a) は初等的でない**：c_2=J''(0)/2 は a=0 作用素の resolvent（2D PDE）を要する。
  small-a fit `J≈1-0.1142a+0.0085a²`。full curve は数値（J(3)=0.737）。
- 「J(a) は PDE-algebraic invariant」の精密な意味：低次データは Gamma 関数で書けるが
  不変量そのものは 2D PDE の解に依存。Case I が横断 Newton data だけで決まったのと対照的。

## 2026-07-27 一般 non-splittable germ の J 分類

`docs/nonsplittable-classification.md` ＋ `python/nonsplittable_classification.py` を追加。
`-x^4+a x^2y^2+y^4` を任意の同次 non-splittable germ へ一般化。

- **分離バックボーン**：W=0 で committor 1D、`J_0 = Z_V/Z_U = ∫e^{-V}/∫e^{-U}`
  （U=V=(·)^d で J_0=1）。初等的（Gamma）。
- **任意結合の1次応答（一般公式）**：`W=Σ c_pq x^p y^q` に対し
  `J'(0)/J_0 = -Σ c_pq <x^p>_d <y^q>_d`, `<x^p>_d = Γ((p+1)/d)/Γ(1/d)`（p偶）, 0（p奇）。
  envelope 定理 + `dJ/dε=-(1/Z_U^2)∫∫W e^{-U-V}` から。
- **パリティ選択則**：奇結合（x^3y^3, x^5y^3）は1次で J に効かない（<x^odd>=0）。
- **非初等性（普遍）**：2次以降は 2D resolvent 依存。分離骨格＋1次応答のみ初等的。
- **数値検証**：degree 4,6,8・8結合で numeric=predicted（対角線一致）、J_0→1、奇結合=0
  （figures/nonsplittable_classification.png）。
- 分類の言明：Case III の J は「代数的スケルトン（初等的 Gamma）＋非初等的 PDE 部分」。
  Case I（Newton data で完全決定）からの階層が定量的に確定。
