## 2026-07-23 横断特異 Laplace 積分 I(T) の検証

### 対象

第一標的 potential

```
F(x,y,z) = (x^2 - 1)^2 / 4 + x^2 (y^2 + z^2) + y^6 + y^2 z^2 + z^6
```

の横断特異 germ `K(y,z) = y^6 + y^2 z^2 + z^6` に付随する Laplace 積分

```
I(T) = ∫∫_{R^2} exp(-(y^6 + y^2 z^2 + z^6)/T) dy dz.
```

### 主結果（解析的に厳密）

**1. 厳密な 1 次元 Bessel 表示。**
象限対称性（×4）と双曲座標 `y^2 = s m, z^2 = s/m`（ヤコビアン `1/(2m)`）により
`K = s^2 + s^3 (m^3 + m^{-3})`。内側積分に標準公式
`∫_0^∞ exp(-a(n + 1/n)) dn/n = 2 K_0(2a)`（`n = m^3`）を適用し `s = sqrt(T) x` と置くと

```
I(T) = (4/3) sqrt(T) ∫_0^∞ exp(-x^2) K_0(2 sqrt(T) x^3) dx.
```

定数 `4/3 = 4 · (1/2) · (1/3)`（象限4・ヤコビアン・`n = m^3`）、変数変換すべて誤り無し。

**2. 小 T 漸近。**
`K_0(w) = -ln(w/2) - γ + O(w^2 ln w)`（`w = 2 sqrt(T) x^3`）と
`∫_0^∞ e^{-x^2} dx = sqrt(π)/2`, `∫_0^∞ e^{-x^2} ln x dx = -(sqrt(π)/4)(γ + 2 ln2)` から

```
I(T) = (sqrt(π)/3) sqrt(T) [ log(1/T) + γ + 6 log 2 ] + O(T^{3/2} log(1/T)).
```

- 先頭係数 `sqrt(π)/3 = 0.590817950301839`
- 補正定数 `γ + 6 log 2 = 4.736098748261204`
- log 多重度 `(log 1/T)^1`（RLCT `λ = 1/2`, `m = 2`）
  — Newton 多面体でも独立確認：単項式 `(6,0),(2,2),(0,6)`、対角線が頂点 `(2,2)` で
  境界に当たり Newton 距離 `= 2 ⟹ λ = 1/2`、0 次元面ヒットゆえ `m = 2`。

剰余は相対的に `O(T)`。これが補正付き比の高速収束の理由。
