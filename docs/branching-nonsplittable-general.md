# 非調和多価 gate：admittance の単変数曲線・調和点摂動・一般 k

`branching-nonsplittable.md`（多価×非分離：admittance が係数依存）を、**閉形式・
調和点摂動・一般 k** の三点で詰める。核心は、族を**調和点を通す形**に取り直すこと：

```
P_{k,t}(x,y) = -Re(w^k) + t·(x²+y²)^{k/2},   w=x+iy,  k 偶数.
```

`t·r^k` は等方的なので**谷を動かさない**（谷は θ_j=2πj/k のまま）。したがって circulant
k 端子ネットワークは全 t で保たれ、変わるのは admittance `a_m` だけ。`t=0` が調和ゲート
`-Re(w^k)`（Case II）、`t≠0` が非調和（Case III）。

## 1. `a_m(a)` の閉形式（単変数への還元）

k=4 では旧パラメータ `a` と厳密に対応：

```
-Re(w^4) + t r^4 = (t-1)x^4 + (6+2t)x²y² + (t-1)y^4  ∝  -x^4 + a x²y² - y^4,
a = (6+2t)/(1-t),   すなわち  t = (a-6)/(a+2).
```

（`a=6 ⇔ t=0`（調和）, `a=2 ⇔ t=-1`（谷の消失境界）, `a→∞ ⇔ t→1`。）

`a_m` は同次 germ のスケール不変量（`P→cP` で不変）なので、**`a_m` は単一変数 `t`
だけの関数**。見かけ上二変数の `a_m(a)` は一本の曲線 `a_m(t)` に潰れる。

**閉形式の言明**：`t≠0` では `a_m(t)` の**初等的閉形式は存在しない**。これは Case III
の `J(a)` と同じ PDE-algebraic 不変量で、2 次元楕円作用素 `div(e^{-P}∇·)` の resolvent を
要する。得られる厳密構造は次の二つに尽きる：

- **厳密な錨点**：`a_m(0) = 2 sin(πm/k)`（調和 Steklov 値, Case II）。
- **調和点まわりの1次係数** `da_m/dt|_0`（§2, envelope 定理の積分。初等的閉形式は無いが
  有限差分不要の明示式で計算可能）。

`nonsplittable-classification.md` の「代数的スケルトン（錨＋1次応答）は初等的、full 関数は
非初等的」という Case III の構図が、多価 admittance でもそのまま成立する。

数値（`s=1`, L=1.9, n=541; 単調減少＝結合増で admittance 減）：

| t | a=(6+2t)/(1-t) | a_1(t) | a_2(t) |
|---|---|---|---|
| −0.50 | 3.333 | 2.1895 | 3.4653 |
| −0.25 | 4.400 | 1.7305 | 2.5843 |
| **0.00** | **6.000** | **1.4173** | **2.0059** |
| +0.25 | 8.667 | 1.1655 | 1.5652 |
| +0.50 | 14.000 | 0.9411 | 1.1986 |

## 2. 調和点摂動 `da_m/da|_{a=6}`（envelope 定理）

admittance は Dirichlet エネルギーの Fourier 対角成分：boundary data `cos(2πmj/k)` の
committor `h_m` に対し、離散 Green 恒等式から

```
E(t) = min_h Σ_edges ½(w_p+w_q)(h_p-h_q)² = S_m · a_m(t),   S_m = Σ_j cos²(2πmj/k),
```

`S_m = k/2`（一般 m）, `= k`（Nyquist `m=k/2`）。envelope 定理（極小点で t 微分＝
被積分の t 偏微分）と `ẇ = -w·∂_tF = -w·r^k` より

```
┌────────────────────────────────────────────────────────────────────┐
│  da_m/dt|_0 = (1/S_m)·dE/dt|_0                                        │
│            = -(1/S_m) Σ_edges ½(w_p r_p^k + w_q r_q^k)(h_m,p - h_m,q)²│
│  （h_m = 調和 germ の committor; 有限差分不要）                        │
└────────────────────────────────────────────────────────────────────┘
```

これは**調和 committor（分数次数ベッセルモード）に対する明示積分**で、Case III の
`J'(0)` と同型（初等的閉形式は無いが厳密な1次係数）。数値では**中心差分と一致**し、
envelope 定理の機構を確認：

| k | m | envelope `da_m/dt|_0` | 中心差分 | `da_m/da|_{a=6}=(1/8)·slope` |
|---|---|---|---|---|
| 4 | 1 | −1.0979 | −1.1050 | **−0.1372** |
| 4 | 2 | −1.9770 | −1.9906 | **−0.2471** |

k=4 の連鎖律：`da/dt|_0 = 8` なので `da_m/da|_{a=6} = (1/8) da_m/dt|_0`。
独立検証：`branching-nonsplittable.md` の a-掃引表の中心差分
（a_1: (1.299−1.587)/2 = −0.144, a_2: (1.795−2.316)/2 = −0.261）と整合。

## 3. 一般 k（非調和多価）

錨点 `a_m(0)=2 sin(πm/k)` は**全 k で普遍**、`a_m(t)`（`t≠0`）は**全 k で係数依存**。
k=4,6 で確認（k=6 は谷が深く narrow なため、スケール不変性 `P→cP` を使い谷深 ~O(1) に
正規化して数値安定化; 有限領域の overshoot を残しつつ Steklov 値に収束）：

| k | m | a_m(0) | 2 sin(πm/k) | envelope `da_m/dt|_0` | 中心差分 |
|---|---|---|---|---|---|
| 4 | 1 | 1.4173 | 1.4142 | −1.0979 | −1.1050 |
| 4 | 2 | 2.0059 | 2.0000 | −1.9770 | −1.9906 |
| 6 | 1 | 1.0287 | 1.0000 | −0.5431 | −0.5466 |
| 6 | 2 | 1.8143 | 1.7321 | −1.4279 | −1.4379 |
| 6 | 3 | 2.1078 | 2.0000 | −1.8253 | −1.8389 |

普遍性（`2 sin(πm/k)`）は germ の**調和性**に由来し、`t=0` から離れると全 k で
admittance が係数依存になる。全 (k,m) で envelope 明示式が中心差分と一致し、§2 の
機構が k に依らず成立することを確認（k=6 の錨点 overshoot は有限領域効果で、領域を
広げれば `2 sin(πm/k)` に収束——`branching-nonsplittable.md` の a=6 収束表と同様）。

## 4. 言明

```
┌──────────────────────────────────────────────────────────────────────┐
│  非調和多価 gate P_{k,t} = -Re w^k + t r^k では:                        │
│   ・ネットワーク（circulant k 端子, 谷 θ_j=2πj/k）は全 t で不変,        │
│   ・a_m はスケール不変ゆえ単一変数 t の関数（a_m(a) は1本の曲線に還元）, │
│   ・a_m(0)=2 sin(πm/k) は全 k 普遍（調和性に由来する厳密な錨点）,        │
│   ・da_m/dt|_0 は envelope 定理の明示積分（Case III の J'(0) と同型）,   │
│   ・full a_m(t) は 2D PDE resolvent 依存で非初等的（t≠0, 全 k）.        │
└──────────────────────────────────────────────────────────────────────┘
```

Case II（普遍 `2 sin`）と Case III（係数依存 capacity）が、「ネットワークは共通・
admittance の普遍性は調和点でのみ・調和点まわりは envelope 定理で初等的スケルトン」
という形で完全に統合される。

## 5. 証拠の区分

- **厳密**：谷を動かさない等方摂動によるネットワーク不変性；`a_m` のスケール不変性
  （単変数化）；`a=(6+2t)/(1-t)`；`a_m(0)=2sin(πm/k)`；envelope 恒等式
  `da_m/dt|_0 = -(1/S_m)Σ½(w r^k)(Δh)²`。
- **数値的に確定**：`a_m(0)→2sin(πm/k)`（k=4,6）；envelope=中心差分（k=4）；
  `da_m/da|_{a=6}` が a-掃引の独立差分と整合；`a_m(t)` の単調減少・係数依存。
- **未決**：`a_m(t)` の非摂動閉形式（Case III 同様に非初等）；一般 k・大結合域；
  高次係数 `d²a_m/dt²`（2D resolvent）。
