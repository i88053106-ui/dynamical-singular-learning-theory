# 理想化 a_m = 2 sin(πm/k) の誤差評価

`branching-gate-slope.md` の閉形式 `a_m = 2 sin(πm/k)`（大 k / Steklov）に対し、真の
admittance `a_m(k, T)` の有限 k・有限 T 補正を評価する。

## 1. 主結果

```
┌──────────────────────────────────────────────────────────────────────┐
│  a_m(k, T) = 2 sin(πm/k) · [ 1 - c_m(k) T + O(T^2) ],   c_m(k) ~ c_m/k^2 │
│  (scale-invariant 極限 T→0 では a_m = 2 sin(πm/k) が全 k で厳密)          │
└──────────────────────────────────────────────────────────────────────┘
```

- **T→0 厳密性**：`a_m(k,T) = A + B T` の線形 fit（信頼域 T∈[0.06,0.15]）で切片 `A` は
  `2 sin(πm/k)` に **~0.1% 一致**（全 k）。よって閉形式は **large-k 漸近でなく、有限 k でも
  scale-invariant 極限で厳密**。残差 ~1e-3（正）は有限井戸半径の数値バイアス。
- **有限 T 補正は O(T/k²)**：相対誤差は T に線形、係数 `c_m(k) ~ c_m/k²`。

`c_1 ≈ 3.4`, `c_2 ≈ 5.8`（m 依存）。実用 envelope：`|a_m/2sin − 1| ≲ 6 T/k²`。

## 3. 何が厳密で何が数値か

- **厳密（変分構造）**：`a_m = inf_h ∫|∇h|² w dA`（Dirichlet エネルギー）ゆえ重み
  `w = e^{ρ^k cos(kφ)/T}` に単調。これが比較（両側 bound）の枠組みを与える。
- **数値的に確定**：T→0 で `a_m = 2 sin(πm/k)`（全 k、~0.1%）；有限 T 補正 `O(T/k²)`。
- **未決（残る唯一の解析課題）**：補正係数 `c_m(k)` の proven-constant 閉形式。
  connection problem 由来で初等的閉形式を持たない見込み。

## 4. 数値信頼域（solver 限界）

重みの動的範囲は `e^{(k/2)/T}`。線形ソルバは float64（~1e16）を超えると精度を失うので、
信頼域は概ね

```
e^{(k/2)/T} ≲ 1e16   <=>   T ≳ (k/2)/37.
```

例：k=6 で T≳0.08、k=8 で T≳0.11 が安全側。T≲0.05 では桁溢れで `a_m` が発散
（物理でなく solver 限界）。本評価はこの範囲内の T で行い、T→0 は線形外挿で得た。

## 5. 帰結（J_k, Λ への伝播）

閉形式が T→0 で厳密ゆえ、`Λ(q) = 2 sin(q/2)`, `Λ'(0⁺) = 1`, `J_k = (k/2)tan(π/2k)`,
`J_∞ = π/4` はすべて **scale-invariant 極限で厳密**。有限 T ではそれぞれ `O(T)` 補正を
受け、envelope は上記 `c_m` から伝播する（`J_k` は各 `a_m` の `O(T/k²)` 補正の加重和）。

## 6. まとめ

理想化の誤差は
- scale-invariant（T→0）極限では **ゼロ**（閉形式は厳密）、
- 有限 T では **O(T/k²)**（線形、係数 `c_m(k) ~ c_m/k²`, `c_1≈3.4`, `c_2≈5.8`）。

残る解析課題は補正係数 `c_m(k)` の閉形式のみ。degree-k branching gate の large-k 構造
（`a_m, Λ, Λ', J_∞`）は、この誤差評価により定量的に閉じた。
