# 分散関係の傾き Λ'(0⁺) = 1 の証明

`branching-gate-largek.md` の `a_m ~ 2πm/k` を精密化し、閉形式と傾き 1 を示す：

```
┌──────────────────────────────────────────────────────────────┐
│   a_m = 2 sin(π m / k),   Λ(q) = 2 sin(q/2),   Λ'(0⁺) = 1.     │
└──────────────────────────────────────────────────────────────┘
```

## 1. 大 k 極限：一様円板 + 境界接点

gate `F = -ρ^k cos(kφ)`、重み `e^{-F/T} = e^{ρ^k cos(kφ)/T}`。固定 `ρ < 1` に対し
`ρ^k → 0`（`k → ∞`）なので **単位円の内部は一様導体（conductivity → 1）** に収束する。
井戸（谷）は `r0 = k^{1/k} → 1` の境界上にあり、深い井戸は重み `e^{(k/2)/T}` が巨大 =
**完全リザーバー（理想接点）**。谷は角度 `φ_j = 2πj/k` に等間隔。

よって large-k 極限は、**一様円板に境界 `ρ=1` 上の k 個の等間隔接点**という古典問題へ
帰着する。

## 2. 円板の Dirichlet-to-Neumann（Steklov）固有値 = |m|

接点が密（`k → ∞`）なら実効境界条件は Dirichlet `h(1,φ) = c(φ)`。mode `c(φ) = e^{imφ}`
の調和拡張は `h(ρ,φ) = ρ^{|m|} e^{imφ}`。境界法線微分（電流密度）は

```
∂_ρ h |_{ρ=1} = |m| e^{imφ}.
```

すなわち単位円板の **DtN（Steklov）作用素は mode `e^{imφ}` に固有値 |m|**（古典的事実）。
これが分散が `q^2`（拡散的）でなく `|q|`（線形）になる理由である。

## 3. 谷 territory 積分 → 2 sin(πm/k)

admittance `a_m` は「谷 0 への正味電流（単位電圧あたり）」。連続極限で谷 0 が担当する
角度領域は Voronoi cell `[-π/k, π/k]`（幅 `2π/k`）。実 mode `c_j = cos(mφ_j)` に対し
電流密度は `|m| cos(mφ)`、`ρ=1` で弧長 `ds = dφ` なので

```
a_m = ∫_{-π/k}^{π/k} |m| cos(mφ) dφ = 2 sin(π m/k).
```

したがって `q = 2πm/k` の分散関係は `Λ(q) = 2 sin(q/2)`、傾きは

```
Λ'(0⁺) = 2 · (1/2) cos(0) = 1.      ∎
```

## 4. 結合と整合性

`Λ(q) = 2 sin(q/2)` の Fourier 級数は無限谷鎖の結合

```
β_s = 8 / (π (4 s^2 - 1))  ~  (2/π)/s^2   (s → ∞),
```

を与え、裾 `(2/π)/s^2` は `Λ'(0⁺) = (π/2)·lim s^2 β_s = (π/2)(2/π) = 1` と整合。
有限リング結合（`a_m = 2 sin(πm/k)` の離散逆変換）は、committor solver から直接抽出した
`β_s` と 3–6 桁一致（k=12：β_1=0.4318 vs 抽出 0.4289 等）。

## 5. 数値検証（`python/branching_steklov_slope.py`）

全 k 谷を `cos(mφ_j)` に固定し谷 0 への電流＝`a_m` を測定、`q ∈ (0, π]` 全域で
`2 sin(π m/k)` と比較（T=0.10）：

| k | m=1 | m=2 | … | 収束 |
|---|---|---|---|---|
| 6 | 0.9915 | 0.9864 | | ratio → 1 |
| 10 | 0.9975 | 0.9955 | | |
| 12 | 0.9987 | 0.9976 | | |
| 16 | 1.0005 | 1.0013 | | |

（表は `a_m / 2sin(πm/k)`。）全測定点は曲線 `2 sin(q/2)` に collapse
（figures/branching_steklov_dispersion.png）。ratio は k 増加・T 減少の両方で 1 へ収束
（一様円板・完全リザーバーの理想化が精密化する方向）。傾き 1 を確認。

## 6. 証拠の区分

- **厳密（機構）**：単位円板の Steklov 固有値 `|m|`（古典）；territory 積分
  `∫_{-π/k}^{π/k}|m|cos(mφ)dφ = 2 sin(πm/k)`；`Λ'(0⁺) = 1`。
- **large-k / T→0 理想化**：一様円板（重み→1）と完全リザーバー（深井戸）への収束。
  数値で `a_m/2sin(πm/k) → 1` を全 q で確認。
- **未決**：理想化の誤差評価（有限 k, 有限 T 補正）の厳密 bound；`J_∞` の閉形式は
  `Λ(q)=2sin(q/2)` から原理的に計算可能（`J_∞ = 1/R_01^∞`）。
