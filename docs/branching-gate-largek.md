# channel admittance の k→∞ 漸近

branching gate の scale-invariant channel admittance `a_m = λ_m/T`（`branching-gate-bs.md`）の
谷数 `k → ∞` 漸近を求める。結論：

```
┌─────────────────────────────────────────────┐
│   a_m(k)  ~  2 π m / k    (m 固定, k → ∞).    │
└─────────────────────────────────────────────┘
```

## 1. 円筒極限（cylinder limit）

gate `F = -ρ^k cos(kφ)`。井戸は `r0 = k^{1/k} → 1`、構造は `k → ∞` で単位円へ集中。
単位円近傍を `u = k(ρ-1)`, `ψ = kφ` でズームすると `ρ^k = (1+u/k)^k → e^u`、

```
F/T -> -e^u cos ψ / (const),      重み e^{-F/T} -> e^{ e^u cos ψ }.
```

計量は `ds^2 ≈ (1/k^2)(du^2 + dψ^2)`（共形平坦）。2 次元 Dirichlet 積分は共形不変なので
`∫|∇h|^2 e^{-F/T} dA` は **k 非依存の普遍的な円筒問題** `∫|∇h|^2 e^{e^u cos ψ} du dψ`
（谷は `ψ = 2πj`）へ収束する。

## 2. 分散関係（dispersion relation）

circulant k端子ネットワークの固有値スペクトルは、`k → ∞` で無限谷鎖の**分散関係**

```
a_m = Λ(q),   Λ(q) = Σ_{s≥1} β_s (1 - cos(q s)),   q = 2π m / k,
```

に収束（`β_s` は鎖の scale-invariant 結合）。`m` 固定なら `q = 2πm/k → 0`。
数値（下記）は `Λ(q) ~ |q|`（slope 1）を示し、これは結合の裾 `β_s ~ (2/π)/s^2` に対応する
（`Σ (1-cos qs)/s^2 = π|q|/2 - q^2/4`）。よって `a_m = Λ(2πm/k) ~ 2πm/k`。

## 3. 数値検証（`python/branching_admittance_asymptotics.py`）

全 k 谷を Fourier mode `v_j = cos(2π m j/k)` に固定し、谷 0 への正味電流＝`λ_m` を直接測定
（Dirichlet form の `T` 因子ゆえ raw current が scale-invariant `a_m` に等しい）。`T=0.12`：

| 3 | 1.671 | — | — | 0.798 | — | — |
| 4 | 1.383 | — | — | 0.881 | — | — |
| 5 | 1.158 | 1.860 | — | 0.922 | 0.740 | — |
| 6 | 0.990 | 1.703 | — | 0.945 | 0.813 | — |

`c_m = a_m k/(2πm)` は m=1,2,3 すべて **単調に 1 へ収束**（figures/branching_admittance_largek.png）。
より大きい m ほど収束は遅い（`q = 2πm/k` が大きく subleading 補正大）。leading slope 1 を <1%
で確認。この直接測定は `a_1(k=4)=1.383`, `a_2(k=4)=1.942` など circulant 逆算値と一致。

## 4. 帰結

- `λ_m ~ 2π m T / k`：長波長 channel の admittance は谷数に反比例。
- 隣接容量定数 `J_k = cap/T` は `k → ∞` で有限値へ飽和（測定 0.836, 0.808, 0.797, 0.792 →
  約 0.79、＝無限谷鎖の隣接 conductance）。
- 結合の裾 `β_s ~ (2/π)/s^2`（`a_m ~ 2πm/k` と等価）。ただし有限 k の個別 `b_s` は
  folding のため裾則から外れ、`β_s → (2/π)/s^2` は k→∞ 漸近としてのみ成立。

## 5. 証拠の区分

- **厳密（構造）**：円筒極限 `e^{e^u cosψ}`（共形不変性の帰結）；circulant スペクトル→分散関係。
- **数値的に確定**：`a_m ~ 2πm/k`（leading slope 1、m=1,2,3 で c_m→1 を <1% 確認）；
  `J_k → ~0.79`。
- **未決**：slope が厳密に 1 である解析的証明（円筒問題の `Λ'(0^+)=1`）；`J_∞` の閉形式；
  subleading 補正の形。
