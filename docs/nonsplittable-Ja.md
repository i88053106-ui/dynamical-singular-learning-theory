# Case III 定数 J(a) の閉形式

`nonsplittable-gate.md` で示した「capacity 定数 J(a) は germ の係数に依存する PDE-algebraic
invariant」の J(a) を調べる。純 homogeneous germ

```
F(x,y) = -x^4 + a x^2 y^2 + y^4
```

は degree 4 homogeneous なので `cap_T = J(a) T`（全 T で厳密）、T=1 で `cap = J(a)`。
scale-invariant J(a) を confinement 無しで直接計算する（reservoir は ±x 谷の奥）。

## 1. 厳密結果

```
┌──────────────────────────────────────────────────────────────────────┐
│  J(0) = 1  (厳密),                                                       │
│  J'(0) = -( Γ(3/4)/Γ(1/4) )^2 = -2π^2/Γ(1/4)^4 ≈ -0.11424  (厳密),       │
│  J(a) = 1 - (2π^2/Γ(1/4)^4) a + O(a^2).                                  │
└──────────────────────────────────────────────────────────────────────┘
```

**J(0) = 1（分離的）。** a=0 で重み `e^{-F} = e^{x^4 - y^4}` は分離、committor は 1 次元
`h(x)`。分離ポテンシャル `-U(x)+V(y)` の committor は `h(x) = C ∫^x e^{-U}`（x のみ）で
`div(e^{U-V}∇h)=0` を満たす。1 次元 conductance は `[∫e^{-U}]^{-1}`、横断因子は `∫e^{-V}`
だから `U=V=(·)^4` で

```
J(0) = [ ∫ e^{-x^4} dx ]^{-1} · ∫ e^{-y^4} dy = 1.
```

**J'(0)（1 次摂動 / envelope 定理）。** `e^{-F_a} = e^{-F_0} e^{-a x^2 y^2}`、
`∂_a e^{-F_a}|_0 = -x^2 y^2 e^{-F_0}`。最小化子は a=0 で `h_0(x)`、
`h_0'(x) = e^{-x^4}/∫e^{-x^4}`。envelope 定理より

```
J'(0) = -∫ |∇h_0|^2 x^2 y^2 e^{-F_0} dx dy
      = -[ ∫ h_0'(x)^2 x^2 e^{x^4} dx ][ ∫ y^2 e^{-y^4} dy ]
      = -( ∫ x^2 e^{-x^4} dx / ∫ e^{-x^4} dx )^2
      = -( Γ(3/4)/Γ(1/4) )^2.
```

反射公式 `Γ(1/4)Γ(3/4) = π√2` より `Γ(3/4)/Γ(1/4) = π√2/Γ(1/4)^2`、よって
`J'(0) = -2π^2/Γ(1/4)^4 ≈ -0.11424`。

## 3. full J(a) は初等的でない

2 次係数 `c_2 = J''(0)/2` は、標準の 2 次摂動論により a=0 作用素の **resolvent**
（`H h_1 = -∂_a∂_h E` の 2 次元 PDE 解 `h_1`）を要する：

```
J''(0) = ∂_a^2 E[h_0] - ⟨∂_a∂_h E, H^{-1} ∂_a∂_h E⟩.
```

第 2 項は 2 次元楕円作用素の逆を含み、初等関数で閉じない。よって

```
J(0), J'(0) は初等的（1, Gamma 関数）だが、J''(0) 以降は 2D PDE の resolvent を要し、
full J(a) は初等的閉形式を持たない。
```

これが「J(a) は PDE-algebraic invariant」の**精密な意味**である：低次データは代数的/
Gamma 関数で書けるが、不変量そのものは 2 次元 PDE の解に本質的に依存する。Case I の
capacity data `(κ,r)` が横断 Newton data だけで（初等的に）決まったのと対照的。

## 4. 証拠の区分

- **厳密**：`J(0) = 1`（分離性）；`J'(0) = -2π^2/Γ(1/4)^4`（1 次摂動 + envelope 定理）；
  `J''(0)` が 2D resolvent を要すること（標準 2 次摂動論）。
- **数値的に確定**：`J(0)→1`（domain-indep）、tangent slope 4 桁一致、full curve J(a)。
- **未決**：`c_2` 以降の係数（2D resolvent の評価）、large-a 漸近、一般 non-splittable
  germ の J の分類。full singular capacity theory の最終フロンティア。
