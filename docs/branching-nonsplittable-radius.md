# 非調和多価 gate：収束半径と大結合域

`branching-nonsplittable-second-order.md` で調和点まわりの Taylor 展開
`a_m(t)=2sin(πm/k)+a'(0)t+½a''(0)t²+…` を曲率まで定めた。本稿はその展開の
**収束半径**と、両端（大結合・弱結合）の**漸近則**を確定する。

## 1. 定義域と両端の退化（厳密）

k=4 の族 `P_{4,t}=-Re(w^4)+t r^4=(t-1)(x^4+y^4)+(6+2t)x²y²` は、`a=(6+2t)/(1-t)`
（`t=(a-6)/(a+2)`）で旧パラメータと対応し、**孤立 4 谷 gate になるのは
`t∈(-1,1)`（⟺ `a∈(2,∞)`）** のみ。全 t で degree-4 同次だが、両端で孤立井戸構造を失う：

```
t → +1 :  P → 8 x² y²          （軸 x=0, y=0 が平坦谷 ＝ Newton 退化; a→∞ 大結合）
t → -1 :  P → -(x²-y²)²         （対角線 x=±y の稜線が 0 に崩落・井戸が合体; a→2）
```

したがって `a_m(t)` は開区間 `(-1,1)` で実解析的（楕円作用素
`div(e^{-P}∇·)` の孤立井戸摂動）、両端 `t=±1` に特異点をもつ。

## 2. 両端の漸近則（数値, k=4）

`python/branching_nonsplittable_radius.py`（L=1.9, n=541）。

**弱結合端 `t→-1`（`a→2`）：平方根発散**

```
a_m(t) ~ C_- (1+t)^{γ_-},   γ_- ≈ -0.43 (m=1), -0.48 (m=2)   （cf. -1/2）
```

対角線の barrier が消えて隣接井戸が短絡 → conductance 発散。`1+t ≈ (a-2)/2` より
**`a_m ~ (a-2)^{-1/2}`（`a→2⁺`）**。端点直近の局所指数は有限領域効果で -0.33〜-0.36 まで
たわむ（井戸合体で L=1.9 が不足）が、窓 fit は -1/2 と整合。

**大結合端 `t→+1`（`a→∞`）：緩やかな代数減衰**

```
a_m(t) ~ C_+ (1-t)^{γ_+},   γ_+ ≈ 0.14 (m=1), 0.17 (m=2)   （小さい正指数）
```

対角 barrier `ax²y²` が高くなり隣接井戸間の輸送が抑制 → `a_m→0`。ただし退化極限
`8x²y²` でも軸は重み 1 の channel なので**減衰は遅い**。`1-t ≈ 8/a` より
**`a_m ~ a^{-γ_+}`（`a→∞`）**：`a=265` でも `a_1≈0.55` と、ゆっくりとしか 0 に向かわない。

## 3. 収束半径 `R = 1`

`a_m(t)` は `(-1,1)` で解析的、両端 `t=±1` に**非整数冪の分岐点**（§2：`γ_-≈-1/2`,
`γ_+≈0.15`、いずれも非整数 ⇒ 真の特異点）。原点 `t=0` から最近接特異点までの距離は
`|±1|=1` なので、

```
┌────────────────────────────────────────────────────────────────────┐
│  a_m(t) の t=0 まわり Taylor 展開の収束半径は  R = 1.                  │
│   ・弱結合端 t=-1: 平方根分岐 (1+t)^{-1/2}  → a_m ~ (a-2)^{-1/2}       │
│   ・大結合端 t=+1: 弱分岐 (1-t)^{γ_+}, γ_+≈0.15 → a_m ~ a^{-γ_+}       │
└────────────────────────────────────────────────────────────────────┘
```

`t=0` の展開係数 `c0,c1,c2 = 1.4173, -1.099, 0.466`（`c2` は 2D resolvent の
`½a''(0)=0.465` と一致）に多項式 fit の `c3≈-0.45, c4≈0.36` を加えた比
`|c_n/c_{n-1}|` は O(1)（`±1` 両特異点の符号交替で振動）で `R~1` と整合するが、
**決定的証拠は §2 の分岐点**。展開が実用精度を保つのは概ね `|t|≲0.3`（`a∈[4,9]` 相当）、
端に近づくほど truncation 誤差が増大する（`branching-nonsplittable-second-order.md` の
osculating parabola 図と一致）。

## 4. 言明

```
非調和多価 gate の admittance a_m(t) は、孤立 4 谷を保つ t∈(-1,1) で解析的、
両端で degree-4 同次のまま退化する:
  t→-1（a→2）  : -(x²-y²)² へ, a_m ~ (a-2)^{-1/2}  （井戸合体・短絡・発散）,
  t→+1（a→∞）: 8x²y² へ,      a_m ~ a^{-γ_+}, γ_+≈0.15 （軸 channel・緩減衰）.
調和点 Taylor 展開の収束半径は両端分岐点により R=1.
```

Case II の普遍 `2sin` は `t=0` の 1 点、Case III の係数依存はその周り `|t|<1` の解析関数、
そして両端は Newton 退化——という**大域像**が、これで一枚に収まる。

## 5. 証拠の区分

- **厳密**：定義域 `t∈(-1,1)`；両端germ `8x²y²`, `-(x²-y²)²`；`(-1,1)` での解析性と
  `R≤1`；`1+t≈(a-2)/2`, `1-t≈8/a` の座標対応。
- **数値的に確定**：`t→-1` の発散指数 `≈-1/2`；`t→+1` の減衰指数 `≈0.15`；
  分岐点による `R=1`；Taylor が `|t|≲0.3` で実用。
- **未決**：`γ_+` の解析値（`8x²y²` 極限の committor）；端点直近の有限領域補正；
  一般 k の端点構造（`Re w^k + t r^k` の退化解析）。
